# Surge first-use session — participant tasks

Use the supplied source package and its README/linked documentation. You do not need to inspect the code. Work only with the included sample and cases. No third-party application is involved.

Record your Windows version, hardware and prerequisite versions. Note start/end times, instructions that were unclear, errors, and any assistance. If you are stuck, say so; your first attempt matters more than finishing with help. The observer will stop the session after 45 minutes if unfinished.

1. Set up Surge and open it using the supplied instructions.
2. Try the included sample, inspect its observations, and stop collection. Explain what you think happened.
3. Save your investigation. Close and reopen Surge, find the case and inspect it again.
4. Rename the case. Export a portable copy and import it into the library. Delete one library entry and describe what remains.
5. Find and inspect the included approved-update, changed-code, unreadable-range and outside-coverage cases. Explain what each result tells you.
6. Describe anything confusing, repetitive or unnecessary, and what you would change first.

The observer will ask about the evidence after you finish. Avoid preparing answers in advance. This session is about the software and its instructions, not evaluating you.

Record: task | completed without help / completed with help / unfinished | elapsed time | wrong turns or assistance | error text | evidence screenshot filename.

Do not include personal files, credentials, or real third-party captures in this session. Screenshots/logs may contain your local username/path; review before sharing.
