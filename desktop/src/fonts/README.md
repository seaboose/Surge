# Offline typography

Bundled from the Google Fonts repository on 6 November 2026:

- `Inter-Variable.ttf`: Inter upright variable font (optical size and weight), https://github.com/google/fonts/tree/main/ofl/inter
- `JetBrainsMono-Variable.ttf`: JetBrains Mono upright variable font (weight), https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Both are redistributed unmodified under the SIL Open Font License 1.1. Keep the accompanying `Inter-OFL.txt` and `JetBrainsMono-OFL.txt` with redistributed font assets. The renderer must load these local files; no font network request is needed.
