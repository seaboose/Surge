# Surge

A student-built anti-cheat research project. **Survive**, a small Unreal game,
records movement so I can compare controlled behaviors, inspect replay evidence,
and write reports. Built with C++, Python, and Electron/React.

**[Download for Windows](https://github.com/seaboose/Surge/releases/download/v0.4.4/Surge-0.4.4-Windows-x64.zip)** ·
**[Preview](https://seaboose.github.io/Surge/)** · **[Code guide](docs/code-map.md)**

Extract the complete ZIP and open **Surge.exe**. Unreal, Python, and Node are not
required. The browser preview is a screenshot tour; the download runs the game.
Follow the [five-minute demo](docs/standalone-demo.md).

This project checks its own game and sample application. It does not inspect
League of Legends or Vanguard, and it does not establish real-cheat detection
accuracy. [Validation and limits](docs/validation.md).
