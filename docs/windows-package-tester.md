# Surge Windows package — participant tasks

Use the supplied Windows package and its opening guide. You do not need developer
tools or to inspect the code. Work only with the included sample and saved examples.
Do not use personal evidence or third-party applications.

Record your Windows version, package filename, start/end times, errors and any
assistance in the blank session record. Keep the first attempt even if a later
retry works. If you are stuck, say so. Stop after 45 minutes if unfinished.

1. Extract the package and open Surge using the supplied instructions. Record any
   Windows warning or failed launch before asking for help.
2. Try the sample, inspect the observations and stop collection. Explain in your
   own words what happened and what the result means.
3. Save the investigation. Close Surge completely, reopen it, find the case and
   inspect it again. Describe what is being shown now.
4. Rename the case, export a copy to a separate folder, import it and delete one
   library entry. Describe what remains and where you would find it.
5. Open the included approved-update, changed-code, unreadable-range and
   outside-coverage examples. Explain what each result tells you.
6. Describe anything confusing, repetitive or unnecessary, and what you would
   change first.

The observer will ask about the evidence after the tasks. Avoid preparing answers
in advance. This session evaluates the software and instructions, not you.

Before sharing screenshots or logs, check for your local username and paths.
Unfamiliar-user acceptance remains pending until an actual unfamiliar participant
completes a recorded session and the acceptance criteria are assessed.
